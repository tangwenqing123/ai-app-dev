# AI 图片生成器 - 规范文档

## 1. 项目概述

- **项目名称**: AI 图片生成器
- **项目类型**: Web 应用 (React + TypeScript)
- **核心功能**: 调用阿里云通义万相 API 实现文字生成图片，支持提示词优化、历史记录、图片下载
- **目标用户**: 想要通过文字描述生成图片的用户

## 2. UI/UX 规范

### 2.1 布局结构

- **整体布局**: 左右分栏 (桌面端 40% / 60%)
- **左侧区域**: 输入面板 (文本框、参数选择、按钮)
- **右侧区域**: 图片展示区
- **响应式断点**:
  - 移动端 (md 以下): 上下布局
  - 桌面端 (md 及以上): 左右分栏

### 2.2 视觉设计

#### 颜色方案 (深色主题)
- **背景色**: `#0a0a0a`
- **卡片背景**: `#1e1e1e`
- **文字颜色**: `#e0e0e0`
- **输入框背景**: `#2d2d2d`
- **输入框边框**: `#404040`
- **主要按钮渐变**: `from-blue-600 to-purple-600`
- **删除按钮**: 红色 `#ef4444`

#### 字体
- **主字体**: 系统默认无衬线字体 (Tailwind default sans)
- **标题大小**: 24px
- **正文大小**: 14px-16px
- **输入框**: 14px

#### 间距系统
- **组件内边距**: 16px (p-4)
- **组件间距**: 24px (gap-6)
- **卡片圆角**: 12px (rounded-xl)

### 2.3 组件列表

1. **InputPanel** - 左侧输入区
   - 多行文本输入框 (textarea)
   - 尺寸选择下拉框 (1K/2K/4K)
   - 智能改写开关 (toggle)
   - "优化提示词" 按钮
   - "生成图片" 按钮

2. **ImageDisplay** - 右侧展示区
   - 图片显示区域
   - 下载按钮 (右上角)
   - 加载动画覆盖层

3. **HistoryPanel** - 历史记录侧边栏
   - 历史记录列表 (按时间倒序)
   - 每条记录显示: 缩略图 + 提示词摘要
   - 单条删除按钮
   - "清空所有" 按钮

4. **LoadingIndicator** - 加载动画
   - 旋转图标 + 提示文字 "AI 正在创作中，请稍候..."

5. **ErrorMessage** - 错误提示
   - 红色提示框显示错误信息

## 3. 功能规范

### 3.1 核心功能

#### 图片生成
- 用户输入图片描述 (prompt)
- 选择图片尺寸: 1K, 2K, 4K
- 开启/关闭智能改写 (默认开启)
- 点击 "生成图片" 按钮调用 API
- 显示加载动画 (10-30秒)
- 生成成功后显示图片
- 提供下载按钮

#### 提示词优化
- 点击 "优化提示词" 按钮
- 调用 DeepSeek API 扩展提示词
- 包含: 主体、场景、风格、光线、色彩、构图等
- 优化结果回填到输入框

#### 历史记录管理
- 自动保存到 localStorage
- 每条记录包含: 时间、原始提示词、优化提示词、图片URL
- 侧边栏显示历史列表 (倒序)
- 点击加载图片
- 支持单条删除
- 支持清空所有

#### 图片下载
- 点击下载按钮
- 文件名: `ai-image-[时间戳].png`

### 3.2 用户交互流程

1. 用户在左侧输入提示词
2. 可选: 点击 "优化提示词" 让 AI 扩展
3. 选择尺寸和智能改写开关
4. 点击 "生成图片"
5. 等待 10-30 秒显示结果
6. 可点击下载保存图片
7. 自动保存到历史记录

### 3.3 错误处理

- 网络错误: "网络连接失败，请稍后重试"
- API Key 无效: "服务配置错误"
- 参数无效: 显示具体错误信息
