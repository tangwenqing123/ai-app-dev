# AI 图片生成器 – 完整项目文档（PRD + 技术设计 + AGENTS.md + 提示词优化指南）

> 本文档融合了产品需求、技术方案、开发规范以及基于30年编辑经验优化的提示词编写指南，供开发时直接使用。


## 一、产品需求文档（PRD）

### 项目概述
一款基于 React + TypeScript 的 AI 图片生成器，调用阿里云通义万相 API 实现文字生成图片。用户输入图片描述，选择图片尺寸和是否开启智能改写，点击生成即可获得精美图片。支持“优化提示词”功能（由 AI 帮助用户扩展描述）、历史记录保存与查看、图片下载。界面采用左右分栏布局，左侧为输入与参数控制区，右侧展示生成的图片。

### 核心功能

#### 1. 图片生成
- 用户通过左侧多行文本框输入图片描述（prompt）。
- 支持选择图片生成尺寸选项（如 1K、2K、4K）。
- 支持开启/关闭“智能改写”（prompt_extend），由大模型自动优化提示词，提升生成效果（默认开启，但会增加 3-4 秒处理时间）。
- 点击“生成图片”按钮，调用 API 获取生成结果。
- 生成过程显示加载动画和提示文字（约 10-30 秒）。
- 生成成功后显示图片，并提供下载按钮。

#### 2. 提示词优化（AI 辅助）
- 提供“优化提示词”按钮。
- 点击后将用户输入发送给 AI，由 AI 将简单描述扩展成详细的图片生成提示词。
- 优化后的提示词需包含：主体、场景、风格、光线、色彩、构图等细节要素。
- 扩展后的提示词自动回填到输入框，供用户编辑或直接使用。

#### 3. 历史记录管理
- 每次生成成功后自动保存记录到 `localStorage`。
- 每条记录包含：生成时间、原始提示词、优化后提示词（如有）、图片 URL。
- 左侧边栏（或底部/右侧）显示历史记录列表，按时间倒序排列。
- 每条记录显示缩略图（可选）+ 提示词摘要。
- 点击历史记录可加载图片大图到展示区。
- 支持单条删除或“清空所有历史”。

#### 4. 图片下载
- 图片生成后，展示区右上角显示下载按钮。
- 点击下载按钮时，将当前图片下载到本地。
- 文件名格式：`ai-image-[时间戳].png`。

### 非功能性需求
- 界面简洁现代，深色主题（背景 `#0a0a0a`，卡片 `#1e1e1e`，文字 `#e0e0e0`）。
- 响应式布局：桌面端左右分栏（比例 40% / 60%），移动端切换为上下布局。
- 生成过程中禁用“生成图片”按钮并显示加载动画（“AI 正在创作中，请稍候…”）。
- 错误处理：API 调用失败、网络错误、参数无效等显示友好提示。
- API Key 通过环境变量管理（`VITE_DASHSCOPE_API_KEY`），严禁硬编码。

### 扩展思路（可选）
- 支持一次生成多张图片（n 参数，最多 4 张）。
- 添加反向提示词功能（negative_prompt），避免生成不想要的内容。
- 支持自定义种子（seed）实现可复现生成。
- 图片编辑功能（风格迁移、图像修复等）。
- 社区分享功能。

### 核心实现要点

#### 1. 数据类型定义
```typescript
type SizeOption = '1K' | '2K' | '4K';  // 通义万相支持的尺寸

interface GenerationRecord {
  id: string;                    // timestamp + random
  originalPrompt: string;        // 原始提示词
  optimizedPrompt?: string;      // 优化后的提示词（如有）
  imageUrl: string;              // 生成的图片 URL
  size: SizeOption;              // 使用的尺寸
  createdAt: number;             // 时间戳
}

interface GenerateParams {
  prompt: string;                // 图片描述
  size: SizeOption;              // 尺寸
  promptExtend: boolean;         // 是否开启智能改写
  n?: number;                    // 图片数量（可选，默认1）
}
```

#### 2. 通义万相 API 封装（`tongyiImageApi.ts`）
- **API 端点**：`https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation`
- **请求方式**：HTTP 同步调用，单次请求即可获得结果
- **模型**：`wan2.7-image-pro`（支持 4K 高清输出）或 `wan2.7-image`（速度更快）
- **请求头**：
  - `Content-Type: application/json`
  - `Authorization: Bearer ${API_KEY}`
- **请求体示例**：
  ```json
  {
    "model": "wan2.7-image-pro",
    "input": {
      "messages": [
        {
          "role": "user",
          "content": [{"text": "一只可爱的橘猫坐在窗台上"}]
        }
      ]
    },
    "parameters": {
      "size": "2K",
      "n": 1,
      "prompt_extend": true,
      "watermark": false
    }
  }
  ```
- **响应处理**：解析返回的 JSON，提取 `output.results` 中的图片 URL。
- **错误处理**：捕获网络错误、API 认证失败、参数无效等异常，返回友好错误信息。

#### 3. “优化提示词”功能
- 点击按钮后，调用 DeepSeek API（与之前的写作助手共用 API Key）完成提示词优化。
- 系统提示词：“你是一位专业的 AI 绘画提示词工程师。请将用户输入的简单描述扩展为详细的图片生成提示词。”
- 优化后的提示词应包含：主体描述、场景/环境、风格/艺术手法、光线与氛围、色彩/色调、构图、质量词等要素。
- 输出仅返回优化后的提示词文本，直接回填输入框。

#### 4. 历史记录
- 使用 `useLocalStorage` hook 存储 `GenerationRecord[]`，键名 `ai-image-history`。
- 每次生成成功后自动保存。
- 历史面板渲染列表，点击任一记录将图片加载到展示区。
- 删除功能：单条删除或全部清空。

#### 5. 图片下载
- 使用 `fetch` 获取图片 Blob，通过 `createObjectURL` 生成临时链接，触发浏览器下载。
- 文件名格式：`ai-image-${Date.now()}.png`。

### 环境变量
- 创建 `.env.local` 文件：
  ```
  VITE_DASHSCOPE_API_KEY=YOUR_DASHSCOPE_API_KEY
  ```
- 如果同时使用提示词优化功能（DeepSeek），还需配置：
  ```
  VITE_DEEPSEEK_API_KEY=YOUR_DEEPSEEK_API_KEY
  ```
- 确保 `.gitignore` 包含 `.env.local`。

### 响应式布局
- 使用 Tailwind 的 `flex flex-col md:flex-row`。
- 左侧区域宽度 `md:w-2/5`，右侧 `md:w-3/5`。
- 历史面板在移动端可置于底部或通过汉堡菜单控制。


## 三、AGENTS.md（开发指令）

### 项目概述
开发一个基于 React + TypeScript + Vite + Tailwind CSS 的 AI 图片生成器，调用阿里云通义万相 API 实现文字生成图片，支持尺寸选择、智能改写、图片下载、历史记录管理等功能。

### 开发规范
- 使用函数式组件 + Hooks，TypeScript 严格模式。
- 样式统一使用 Tailwind CSS，避免自定义 CSS。
- 组件拆分：`InputPanel`、`ImageDisplay`、`HistoryPanel`、`LoadingIndicator` 等。
- API 调用统一封装在 `services/tongyiImageApi.ts`。
- 环境变量名以 `VITE_` 开头，API Key 不硬编码。
- 代码添加必要注释，特别是 API 调用和异步错误处理。
- 所有用户配置（历史记录）使用 `localStorage`。

### 功能实现顺序（建议）
1. **初始化项目**：Vite + React + TypeScript + Tailwind CSS。
2. **安装依赖**：`lucide-react` 等。
3. **定义类型**：`types/image.ts` 定义 `GenerationRecord`、`SizeOption` 等。
4. **实现 API 封装**：`tongyiImageApi.ts`，先测试能否成功生成图片（用简单固定 prompt 验证 API Key 是否有效）。
5. **搭建基础 UI**：左右分栏布局，左侧包含文本框、参数选项、生成按钮；右侧展示区占位。
6. **实现图片生成功能**：连接 API，处理加载状态和错误提示。
7. **实现提示词优化**：调用 DeepSeek API 扩展提示词，回填输入框。
8. **实现历史记录**：使用 `useLocalStorage`，添加侧边栏历史列表，支持点击加载和删除。
9. **实现图片下载**：添加下载按钮和下载逻辑。
10. **完善用户体验**：优化加载动画、错误提示、移动端适配。

### 设计要求
- 深色主题：背景 `#0a0a0a`，卡片背景 `#1e1e1e`，文字 `#e0e0e0`。
- 输入框背景 `#2d2d2d`，边框 `#404040`。
- 生成按钮使用渐变（`from-blue-600 to-purple-600`），hover 效果。
- 参数选择使用下拉框或单选按钮，样式统一。
- 历史记录项 hover 高亮，删除按钮红色。
- 展示区图片自适应宽度，最大高度限制。

### 注意事项
- **API Key 安全**：绝对不能硬编码，必须使用环境变量。提交代码前检查无泄露。
- **生成时长提示**：通义万相生成图片通常需要 10-30 秒，加载提示要清晰明确，告诉用户“正在生成中，请稍候”。
- **并发控制**：生成过程中禁用“生成图片”按钮，防止重复请求。
- **错误处理**：
  - 网络错误：显示“网络连接失败，请稍后重试”。
  - API Key 无效：显示“服务配置错误”（开发期检查）。
  - 参数超出限制：提示词最长 2100 字符，建议前端做长度校验。
- **响应式布局**：移动端确保按钮尺寸足够点击（最小 44x44px），历史面板可折叠。
- **成本控制**：测试时使用 `wan2.7-image`（速度更快）或减少测试次数，避免过多调用产生费用。

### 扩展思路（后续可选）
- 支持一次生成多张图片（n=1~4）。
- 添加反向提示词（negative_prompt）功能。
- 支持自定义种子，实现可复现生成。
- 图片编辑功能（扩图、去水印、风格迁移等）。


## 四、通义万相提示词优化指南（30年编辑经验版）

### 提示词的基本结构

通义万相支持中英文提示词，最大长度 2100 个字符。一个好的图片生成提示词应包含以下核心要素：

**基础公式（适合新手）** ：
> **提示词 = 主体 + 场景/环境 + 风格**

- **主体**：图片的主要表现对象，可以是人、动物、植物或物品。示例：`“一只可爱的橘猫”`
- **场景**：主体所处的环境，包括室内/室外、季节、天气等。示例：`“坐在窗台上，外面下着雨”`
- **风格**：定义图像的艺术风格。示例：`“写实风格”`

**进阶公式（适合有经验用户）** ：
> **提示词 = 主体 + 场景 + 风格 + 镜头语言 + 光线/氛围 + 质量修饰**

- **主体**：增加特征、动作等细节。示例：`“一位25岁的中国女孩，圆脸，穿着优雅的民族服装，半身特写”`
- **场景**：更细致的环境描述。示例：`“室外，傍晚时分，街灯亮起”`
- **风格**：明确风格名称。示例：`“商业摄影”、“水彩风格”、“电影级光照”`
- **镜头语言**：景别（特写/中景/全景）、视角（俯视/平视/仰视）。示例：`“半身特写”、“浅景深”`
- **光线与氛围**：光线类型和情绪基调。示例：`“金色日落的光线，温暖的氛围”`
- **质量修饰**：画质关键词。示例：`“4K，高清画质，细腻纹理”`

### 常用关键词词典

#### 风格关键词
| 类别 | 关键词示例 |
|------|-----------|
| 写实风格 | `photorealistic`, `realistic`, `detailed texture`, `HD`, `4K` |
| 插画风格 | `illustration`, `digital art`, `vector art` |
| 水彩风格 | `watercolor`, `soft colors`, `artistic` |
| 油画风格 | `oil painting`, `impressionist`, `Van Gogh style` |
| 动漫风格 | `anime style`, `cartoon`, `manga` |
| 赛博朋克 | `cyberpunk`, `neon lights`, `futuristic city` |

#### 光线关键词
| 类别 | 关键词示例 |
|------|-----------|
| 自然光 | `natural lighting`, `soft daylight`, `morning light` |
| 日落光 | `golden hour`, `sunset glow`, `warm light` |
| 电影光 | `cinematic lighting`, `dramatic shadows`, `Rembrandt light` |
| 工作室光 | `studio lighting`, `softbox`, `key light` |

#### 构图与镜头关键词
| 类别 | 关键词示例 |
|------|-----------|
| 景别 | `close-up`, `medium shot`, `full body`, `wide angle` |
| 视角 | `low angle`, `high angle`, `bird's eye view`, `first-person view` |
| 特效 | `shallow depth of field`, `bokeh`, `motion blur` |

### 提示词示例对比

❌ **平淡的提示词**：
> `“一只猫”` → 生成结果非常普通，缺乏细节。

✅ **优化的提示词（基础公式）** ：
> `“一只可爱的橘猫，坐在窗台上看着外面的雨，温暖的室内光线，柔和的色调，写实风格”`

✅ **高级优化的提示词（进阶公式）** ：
> `“一只毛色鲜艳的橘猫慵懒地趴在窗台软垫上，透过玻璃凝望着窗外的绵绵细雨，温暖的台灯光晕洒在它细腻的皮毛上，背景是模糊的客厅，浅景深突出猫咪主体，柔和的暖色调营造宁静氛围，8K超高清画质，专业摄影水准，电影级布光，极致细腻的毛发细节”`

### 实用优化技巧

1. **中英文皆可，但英文效果可能更佳**：通义万相的中文理解能力已经很强，但如需更精准的效果，可尝试先用英文优化再使用。
2. **描述越具体，效果越好**：不要说“一个男人”，要说“一位30岁穿着黑色西装的亚裔男人”。
3. **开启智能改写（prompt_extend: true）** ：通义万相自带大模型提示词优化功能，默认即开启，可显著提升生成效果。
4. **使用负面提示词**：如果不希望图片中出现某些元素，可用 `negative_prompt` 排除，例如 `“人物”`、`“文字”`、`“水印”`。
5. **尝试不同尺寸**：根据需求选择合适的尺寸，1K 适合快速预览，4K 适合最终输出。

### 通义万相独有特性

**智能改写（prompt_extend）** ：通义万相 V2 版本支持大模型智能改写 prompt。当开启此功能时，阿里云的大模型会自动优化你的提示词，补充缺失的细节元素，显著提升生成质量。尽管会增加 3-4 秒处理时间，但非常推荐默认开启。

**反向提示词（negative_prompt）** ：V2 版本支持反向提示词，帮助排除不想要的画面内容。例如，如果你不希望生成图片中出现人物，可以设置 `negative_prompt: "人物"`。

**水印控制**：可通过 `watermark: false` 关闭默认水印（默认为关闭）。
